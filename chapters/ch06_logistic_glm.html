6  羅吉斯迴歸與廣義線性模型

6.1 本章導讀

在許多實際應用中，我們感興趣的反應變數並非連續的數值，而是離散的類別（Category / Class）。例如：病患是否罹患心臟病（是/否）、金融交易是否為詐欺（真/偽）、客戶次月是否流失。這類問題統稱為分類問題（Classification）。

初學者常見的直覺是：「能否直接對二元類別（0 與 1）套用線性迴歸？」答案是不可行且理論上有重大缺陷。為了將線性模型的優點推廣至非連續目標，統計學家提出了廣義線性模型（Generalized Linear Models, GLM），而其中的皇冠正是羅吉斯迴歸（Logistic Regression）。

本章將剖析線性迴歸應用於分類的內在矛盾；定義勝算（Odds）與 Logit 轉換；嚴格推導基於極大似然估計（MLE）的交叉熵損失函數；給出支撐數值求解的牛頓-拉夫森法（Newton-Raphson）與迭代加權最小平方法（IRLS）之完整推導；提供一組 4 筆樣本的手把手數值推演；介紹多類別的 Softmax 迴歸與偏差（Deviance）模型診斷指標；最後在 R 與 Python 中進行二元分類與模型診斷實戰。

6.2 6.1 為什麼線性迴歸不適用於分類？

6.2.1 6.1.1 預測機率溢出問題

若對二元標籤 Y \in \{0, 1\} 擬合 OLS 模型 Y = \boldsymbol{X}\boldsymbol{\beta} + \epsilon，並將預測值 \hat{Y} 視為事件發生的條件機率 P(Y=1 \mid \boldsymbol{X})： * 線性函數 \boldsymbol{x}^\top \boldsymbol{\beta} 的取值範圍為 (-\infty, \infty)。 * 當輸入特徵偏向極端值時，預測值將不可避免地小於 0 或大於 1，嚴重違背機率公理（0 \le P \le 1）。

6.2.2 6.1.2 異變異數性（Heteroscedasticity）

對於二元伯努利隨機變數 Y，其條件變異數為： \mathrm{Var}(Y \mid \boldsymbol{X}) = p(\boldsymbol{X})\left(1 - p(\boldsymbol{X})\right) 誤差項的變異數直接取決於輸入特徵 \boldsymbol{X}，徹底破壞了 Gauss-Markov 定理中的同變異數假設。

6.2.3 6.1.3 類別編碼偏置（多類別時）

若目標變數有三個類別（例如急診室病患病情：1=輕症, 2=中症, 3=重症），若直接指派數值 1, 2, 3，OLS 會隱含「輕症與中症的差距」等於「中症與重症的差距」，甚至認為輕症與重症的平均就是中症，這種人為度量順序會扭曲資料本質。

6.3 6.2 羅吉斯模型設定與勝算比

6.3.1 6.2.1 Sigmoid 函數與 Logit 轉換

為了將實數軸 (-\infty, \infty) 嚴格壓縮至機率區間 (0, 1)，羅吉斯迴歸採用 標準羅吉斯函數（Standard Logistic Function / Sigmoid）：

p(\boldsymbol{x}) \triangleq P(Y = 1 \mid \boldsymbol{X} = \boldsymbol{x}) = \sigma(\boldsymbol{x}^\top \boldsymbol{\beta}) \triangleq \frac{1}{1 + e^{-\boldsymbol{x}^\top \boldsymbol{\beta}}} = \frac{e^{\boldsymbol{x}^\top \boldsymbol{\beta}}}{1 + e^{\boldsymbol{x}^\top \boldsymbol{\beta}}} \tag{6.1}

6.3.1.1 核心代數轉換：

  1. 勝算（Odds）：事件發生機率與不發生機率的比值： \mathrm{Odds} \triangleq \frac{p(\boldsymbol{x})}{1 - p(\boldsymbol{x})} = \frac{\frac{e^{\boldsymbol{x}^\top \boldsymbol{\beta}}}{1 + e^{\boldsymbol{x}^\top \boldsymbol{\beta}}}}{\frac{1}{1 + e^{\boldsymbol{x}^\top \boldsymbol{\beta}}}} = e^{\boldsymbol{x}^\top \boldsymbol{\beta}} \in (0, \infty)
  2. 對數勝算（Log-Odds / Logit）：對勝算取自然對數： \ln\left( \frac{p(\boldsymbol{x})}{1 - p(\boldsymbol{x})} \right) = \boldsymbol{x}^\top \boldsymbol{\beta} = \beta_0 + \beta_1 x_1 + \cdots + \beta_p x_p \tag{6.2}

統計解釋（勝算比 Odds Ratio, OR）： 當其他特徵固定時，特徵 x_j 每增加 1 個單位，其勝算將乘以 e^{\beta_j} 倍！ * 若 \beta_j > 0 \implies e^{\beta_j} > 1，特徵增加會提升正類別的勝算。 * 若 \beta_j = 0 \implies e^{\beta_j} = 1，該特徵對勝算毫無影響。 * 若 \beta_j < 0 \implies e^{\beta_j} < 1，特徵增加會降低正類別的勝算。

6.4 6.3 極大似然估計（MLE）與交叉熵損失

因為非線性 Sigmoid 函數的存在，最小平方法無法求得解析解。統計上我們採用極大似然估計（Maximum Likelihood Estimation, MLE）。

6.4.1 6.3.1 似然函數推導

設樣本獨立同分佈，給定標籤 y_i \in \{0, 1\}，條件機率可統整寫為伯努利形式： P(Y = y_i \mid \boldsymbol{x}_i) = p(\boldsymbol{x}_i)^{y_i} \left(1 - p(\boldsymbol{x}_i)\right)^{1 - y_i}

全體 n 筆獨立樣本的聯合似然函數（Likelihood Function）為： L(\boldsymbol{\beta}) = \prod_{i=1}^n p(\boldsymbol{x}_i)^{y_i} \left(1 - p(\boldsymbol{x}_i)\right)^{1 - y_i}

取自然對數得對數似然函數（Log-Likelihood）： \ell(\boldsymbol{\beta}) = \sum_{i=1}^n \left[ y_i \ln p(\boldsymbol{x}_i) + (1 - y_i) \ln (1 - p(\boldsymbol{x}_i)) \right] \tag{6.3}

將 p(\boldsymbol{x}_i) = \frac{e^{\boldsymbol{x}_i^\top \boldsymbol{\beta}}}{1 + e^{\boldsymbol{x}_i^\top \boldsymbol{\beta}}} 代入展開： \begin{aligned} \ell(\boldsymbol{\beta}) &= \sum_{i=1}^n \left[ y_i \ln\left( \frac{p(\boldsymbol{x}_i)}{1 - p(\boldsymbol{x}_i)} \right) + \ln(1 - p(\boldsymbol{x}_i)) \right] \\ &= \sum_{i=1}^n \left[ y_i (\boldsymbol{x}_i^\top \boldsymbol{\beta}) - \ln(1 + e^{\boldsymbol{x}_i^\top \boldsymbol{\beta}}) \right] \end{aligned} \tag{6.4}

在機器學習中，我們通常將其乘以 -1/n，轉換為最小化二元交叉熵損失（Binary Cross-Entropy Loss）： \mathcal{L}(\boldsymbol{\beta}) = -\frac{1}{n}\ell(\boldsymbol{\beta}) = -\frac{1}{n}\sum_{i=1}^n \left[ y_i \ln p_i + (1 - y_i)\ln(1 - p_i) \right]

6.5 6.4 數值最佳化：牛頓-拉夫森法與 IRLS

6.5.1 6.4.1 一階梯度向量與二階 Hessian 矩陣推導

首先計算 Sigmoid 函數的導數性質： \frac{d\sigma(z)}{dz} = \sigma(z)(1 - \sigma(z)) 故 \frac{\partial p_i}{\partial \boldsymbol{\beta}} = p_i (1 - p_i) \boldsymbol{x}_i。

6.5.1.1 1. 一階梯度（Gradient Vector）：

對式 (6.4) 的 \boldsymbol{\beta} 求一階偏導： \nabla_{\boldsymbol{\beta}} \ell(\boldsymbol{\beta}) = \sum_{i=1}^n \left( y_i \boldsymbol{x}_i - \frac{e^{\boldsymbol{x}_i^\top \boldsymbol{\beta}}}{1 + e^{\boldsymbol{x}_i^\top \boldsymbol{\beta}}} \boldsymbol{x}_i \right) = \sum_{i=1}^n (y_i - p_i)\boldsymbol{x}_i = \boldsymbol{X}^\top (\boldsymbol{y} - \boldsymbol{p}) \tag{6.5}

其中 \boldsymbol{p} = (p_1, p_2, \dots, p_n)^\top \in \mathbb{R}^n。

6.5.1.2 2. 二階 Hessian 矩陣：

對梯度再次求導： \nabla^2_{\boldsymbol{\beta}} \ell(\boldsymbol{\beta}) = \frac{\partial}{\partial \boldsymbol{\beta}^\top} \left( \sum_{i=1}^n (y_i - p_i)\boldsymbol{x}_i \right) = -\sum_{i=1}^n \boldsymbol{x}_i \left( \frac{\partial p_i}{\partial \boldsymbol{\beta}^\top} \right) = -\sum_{i=1}^n p_i (1 - p_i) \boldsymbol{x}_i \boldsymbol{x}_i^\top

定義對角權重矩陣 \boldsymbol{W} \in \mathbb{R}^{n \times n}： \boldsymbol{W} = \mathrm{diag}\left( p_1(1 - p_1), \, p_2(1 - p_2), \, \dots, \, p_n(1 - p_n) \right) 則 Hessian 矩陣以簡潔的矩陣形式表示為： \boldsymbol{H} = \nabla^2 \ell(\boldsymbol{\beta}) = -\boldsymbol{X}^\top \boldsymbol{W} \boldsymbol{X} \tag{6.6}

6.5.1.3 凸性分析（全域最優解保證）：

由於 0 < p_i < 1，權重矩陣 \boldsymbol{W} 的對角元素恆為正數（p_i(1-p_i) > 0），故 \boldsymbol{W} 為正定對角矩陣。 對於任意非零向量 \boldsymbol{v} \in \mathbb{R}^{p+1}： \boldsymbol{v}^\top \boldsymbol{H} \boldsymbol{v} = -\boldsymbol{v}^\top (\boldsymbol{X}^\top \boldsymbol{W} \boldsymbol{X})\boldsymbol{v} = -(\boldsymbol{X}\boldsymbol{v})^\top \boldsymbol{W} (\boldsymbol{X}\boldsymbol{v}) \le 0 Hessian 矩陣恆為半負定（Negative Semi-Definite），證明對數似然函數 \ell(\boldsymbol{\beta}) 是嚴格凹函數（Concave Function），沒有任何局部極大值的陷阱，保證數值最佳化必收斂至全域唯一極值點！

6.5.2 6.4.2 迭代加權最小平方法（IRLS）推導

利用多變數牛頓-拉夫森法（Newton-Raphson Update）： \boldsymbol{\beta}^{(t+1)} = \boldsymbol{\beta}^{(t)} - \left[ \nabla^2 \ell(\boldsymbol{\beta}^{(t)}) \right]^{-1} \nabla \ell(\boldsymbol{\beta}^{(t)})

代入式 (6.5) 與式 (6.6)： \begin{aligned} \boldsymbol{\beta}^{(t+1)} &= \boldsymbol{\beta}^{(t)} - \left[ -\boldsymbol{X}^\top \boldsymbol{W}_t \boldsymbol{X} \right]^{-1} \left[ \boldsymbol{X}^\top (\boldsymbol{y} - \boldsymbol{p}_t) \right] \\ &= \boldsymbol{\beta}^{(t)} + (\boldsymbol{X}^\top \boldsymbol{W}_t \boldsymbol{X})^{-1} \boldsymbol{X}^\top (\boldsymbol{y} - \boldsymbol{p}_t) \\ &= (\boldsymbol{X}^\top \boldsymbol{W}_t \boldsymbol{X})^{-1} \left[ (\boldsymbol{X}^\top \boldsymbol{W}_t \boldsymbol{X})\boldsymbol{\beta}^{(t)} + \boldsymbol{X}^\top (\boldsymbol{y} - \boldsymbol{p}_t) \right] \\ &= (\boldsymbol{X}^\top \boldsymbol{W}_t \boldsymbol{X})^{-1} \boldsymbol{X}^\top \boldsymbol{W}_t \left[ \boldsymbol{X}\boldsymbol{\beta}^{(t)} + \boldsymbol{W}_t^{-1}(\boldsymbol{y} - \boldsymbol{p}_t) \right] \end{aligned}

定義調整後工作反應變數（Adjusted Working Response） \boldsymbol{z}_t \in \mathbb{R}^n： \boldsymbol{z}_t \triangleq \boldsymbol{X}\boldsymbol{\beta}^{(t)} + \boldsymbol{W}_t^{-1}(\boldsymbol{y} - \boldsymbol{p}_t) \tag{6.7}

此時牛頓法更新式完美化為： \boldsymbol{\beta}^{(t+1)} = (\boldsymbol{X}^\top \boldsymbol{W}_t \boldsymbol{X})^{-1} \boldsymbol{X}^\top \boldsymbol{W}_t \boldsymbol{z}_t \tag{6.8}

6.5.2.1 深刻結論：

式 (6.8) 正好是以 \boldsymbol{W}_t 為權重矩陣、對響應變數 \boldsymbol{z}_t 進行的加權最小平方法（Weighted Least Squares, WLS）！ 這項精妙的代數等價性，使統計學家將求解 GLM 的演算法命名為迭代加權最小平方法（Iteratively Reweighted Least Squares, IRLS）。

6.6 6.5 手把手數值推演：4 筆資料之 IRLS 首步手算

為了使讀者直觀感受 IRLS 的內部運作機制，我們構造一組 4 筆樣本的 1D 分類資料：

樣本編號 i x_i 真實標籤 y_i
1 0 0
2 1 0
3 2 1
4 3 1

設計矩陣（含截距項）與標籤向量為： \boldsymbol{X} = \begin{bmatrix} 1 & 0 \\ 1 & 1 \\ 1 & 2 \\ 1 & 3 \end{bmatrix}, \quad \boldsymbol{y} = \begin{bmatrix} 0 \\ 0 \\ 1 \\ 1 \end{bmatrix}

6.6.1 步驟 1：初始設定

設初始參數向量為零向量： \boldsymbol{\beta}^{(0)} = \begin{bmatrix} \beta_0^{(0)} \\ \beta_1^{(0)} \end{bmatrix} = \begin{bmatrix} 0 \\ 0 \end{bmatrix}

6.6.2 步驟 2：計算各點預測機率與權重

對各樣本計算線性得分 \eta_i = \boldsymbol{x}_i^\top \boldsymbol{\beta}^{(0)} = 0： p_i = \sigma(0) = \frac{1}{1 + e^0} = 0.5, \quad \forall i \in \{1, 2, 3, 4\} 預測機率向量為 \boldsymbol{p}_0 = [0.5, 0.5, 0.5, 0.5]^\top。 殘差項 \boldsymbol{y} - \boldsymbol{p}_0： \boldsymbol{y} - \boldsymbol{p}_0 = \begin{bmatrix} 0 - 0.5 \\ 0 - 0.5 \\ 1 - 0.5 \\ 1 - 0.5 \end{bmatrix} = \begin{bmatrix} -0.5 \\ -0.5 \\ +0.5 \\ +0.5 \end{bmatrix} 對角權重矩陣元素：w_i = p_i(1 - p_i) = 0.5 \times 0.5 = 0.25： \boldsymbol{W}_0 = \mathrm{diag}(0.25, 0.25, 0.25, 0.25) = 0.25 \, \boldsymbol{I}_4

6.6.3 步驟 3：計算一階梯度與 Hessian 矩陣

  • 梯度向量： \nabla \ell(\boldsymbol{\beta}^{(0)}) = \boldsymbol{X}^\top (\boldsymbol{y} - \boldsymbol{p}_0) = \begin{bmatrix} 1 & 1 & 1 & 1 \\ 0 & 1 & 2 & 3 \end{bmatrix} \begin{bmatrix} -0.5 \\ -0.5 \\ 0.5 \\ 0.5 \end{bmatrix} = \begin{bmatrix} -0.5 - 0.5 + 0.5 + 0.5 \\ 0(-0.5) + 1(-0.5) + 2(0.5) + 3(0.5) \end{bmatrix} = \begin{bmatrix} 0 \\ 2.0 \end{bmatrix}
  • 加權散佈矩陣 \boldsymbol{X}^\top \boldsymbol{W}_0 \boldsymbol{X}： \boldsymbol{X}^\top \boldsymbol{W}_0 \boldsymbol{X} = 0.25 \begin{bmatrix} 1 & 1 & 1 & 1 \\ 0 & 1 & 2 & 3 \end{bmatrix} \begin{bmatrix} 1 & 0 \\ 1 & 1 \\ 1 & 2 \\ 1 & 3 \end{bmatrix} = 0.25 \begin{bmatrix} 4 & 6 \\ 6 & 14 \end{bmatrix} = \begin{bmatrix} 1.0 & 1.5 \\ 1.5 & 3.5 \end{bmatrix}
  • 求逆矩陣 (\boldsymbol{X}^\top \boldsymbol{W}_0 \boldsymbol{X})^{-1}： 行列式 \det = (1.0)(3.5) - (1.5)^2 = 3.5 - 2.25 = 1.25 = \frac{5}{4}。 (\boldsymbol{X}^\top \boldsymbol{W}_0 \boldsymbol{X})^{-1} = \frac{1}{1.25} \begin{bmatrix} 3.5 & -1.5 \\ -1.5 & 1.0 \end{bmatrix} = \begin{bmatrix} 2.8 & -1.2 \\ -1.2 & 0.8 \end{bmatrix}

6.6.4 步驟 4：執行參數更新

由牛頓法： \boldsymbol{\beta}^{(1)} = \boldsymbol{\beta}^{(0)} + (\boldsymbol{X}^\top \boldsymbol{W}_0 \boldsymbol{X})^{-1} \nabla \ell(\boldsymbol{\beta}^{(0)}) = \begin{bmatrix} 0 \\ 0 \end{bmatrix} + \begin{bmatrix} 2.8 & -1.2 \\ -1.2 & 0.8 \end{bmatrix} \begin{bmatrix} 0 \\ 2.0 \end{bmatrix} = \begin{bmatrix} -2.4 \\ 1.6 \end{bmatrix}

6.6.5 步驟 5：加權最小平方 WLS 視角驗證

計算工作反應變數 \boldsymbol{z}_0 = \boldsymbol{X}\boldsymbol{\beta}^{(0)} + \boldsymbol{W}_0^{-1}(\boldsymbol{y} - \boldsymbol{p}_0) = \boldsymbol{0} + \frac{1}{0.25}(\boldsymbol{y} - \boldsymbol{p}_0) = 4(\boldsymbol{y} - \boldsymbol{p}_0)： \boldsymbol{z}_0 = \begin{bmatrix} 4(-0.5) \\ 4(-0.5) \\ 4(0.5) \\ 4(0.5) \end{bmatrix} = \begin{bmatrix} -2 \\ -2 \\ 2 \\ 2 \end{bmatrix} 計算 \boldsymbol{X}^\top \boldsymbol{W}_0 \boldsymbol{z}_0： \boldsymbol{X}^\top \boldsymbol{W}_0 \boldsymbol{z}_0 = 0.25 \begin{bmatrix} 1 & 1 & 1 & 1 \\ 0 & 1 & 2 & 3 \end{bmatrix} \begin{bmatrix} -2 \\ -2 \\ 2 \\ 2 \end{bmatrix} = 0.25 \begin{bmatrix} 0 \\ 8 \end{bmatrix} = \begin{bmatrix} 0 \\ 2 \end{bmatrix} 套用 WLS 解： \boldsymbol{\beta}^{(1)} = (\boldsymbol{X}^\top \boldsymbol{W}_0 \boldsymbol{X})^{-1} (\boldsymbol{X}^\top \boldsymbol{W}_0 \boldsymbol{z}_0) = \begin{bmatrix} 2.8 & -1.2 \\ -1.2 & 0.8 \end{bmatrix} \begin{bmatrix} 0 \\ 2 \end{bmatrix} = \begin{bmatrix} -2.4 \\ 1.6 \end{bmatrix} 牛頓步與 WLS 閉式解完美一致！

💡 幾何意義解讀： 在僅僅第 1 步迭代後，模型的分界決策面為 -2.4 + 1.6x = 0 \implies x^* = \frac{2.4}{1.6} = 1.5！ 決策分界線精準落在類別 0（x \in \{0, 1\}）與類別 1（x \in \{2, 3\}）的中間點 x=1.5 處，展現了二階最佳化極高的收斂效率。

6.7 6.6 模型評估與診斷指標：偏差（Deviance）與 AIC

在廣義線性模型中，衡量配適度優劣不再使用最小平方法的殘差平方和（\mathrm{RSS}），而是使用偏差（Deviance）。

6.7.1 6.6.1 飽和模型與偏差定義

  • 飽和模型（Saturated Model）：假設模型參數個數等於樣本數（p = n），能完美配適每一筆資料，其對數似然為 \ell_{\text{sat}}。
  • 擬合模型（Fitted Model）：使用 p+1 個參數估計，其最大對數似然為 \ell(\hat{\boldsymbol{\beta}})。
  • 殘差偏差（Residual Deviance, D）： D \triangleq 2 \left[ \ell_{\text{sat}} - \ell(\hat{\boldsymbol{\beta}}) \right] 在二元羅吉斯迴歸中，飽和模型的 \hat{p}_i = y_i，故 \ell_{\text{sat}} = 0。因此： D = -2 \ell(\hat{\boldsymbol{\beta}}) = -2 \sum_{i=1}^n \left[ y_i \ln \hat{p}_i + (1 - y_i) \ln(1 - \hat{p}_i) \right]
  • 虛無偏差（Null Deviance, D_0）：僅包含截距項（所有樣本預測機率皆為 \bar{y}）的偏差值。
  • 模型顯著性之似然比檢定（Likelihood Ratio Test, LRT）： \Delta D = D_0 - D = 2\left[ \ell(\hat{\boldsymbol{\beta}}) - \ell(\hat{\beta}_0) \right] \sim \chi^2_p 若 p-value 極小，拒絕虛無假設，證明引入的 p 個特徵整體對模型有顯著解釋力。

6.7.2 6.6.2 赤池資訊準則（AIC）

\mathrm{AIC} = -2\ell(\hat{\boldsymbol{\beta}}) + 2(p + 1) = D + 2(p + 1) 在配適優度與參數懲罰項之間取得平衡，數值越小代表模型越優。

6.8 6.7 多類別推廣：Softmax 迴歸

當類別數量 K > 2 時，模型推廣為多項羅吉斯迴歸（Multinomial Logistic Regression / Softmax）：

P(Y = k \mid \boldsymbol{x}) = \frac{e^{\boldsymbol{x}^\top \boldsymbol{\beta}_k}}{\sum_{l=1}^K e^{\boldsymbol{x}^\top \boldsymbol{\beta}_l}}, \quad k = 1, 2, \dots, K \tag{6.9}

為了保證參數可辨識性，通常固定最後一類作為基準類別（令 \boldsymbol{\beta}_K = \boldsymbol{0}）。Softmax 函數是現代深度神經網路輸出層分類任務的標準配置。

# 2. 手刻迭代加權最小平方法 (IRLS)
def fit_irls_logistic(X, y, max_iter=20, tol=1e-6):
    n_samples, p_features = X.shape
    beta = np.zeros(p_features) # 初始化為零
    
    for iteration in range(max_iter):
        p = 1.0 / (1.0 + np.exp(-X @ beta))
        p = np.clip(p, 1e-15, 1 - 1e-15) # 防止數值溢出
        
        w = p * (1.0 - p)
        W = np.diag(w)
        
        # 工作反應變數 z
        z = X @ beta + (y - p) / w
        
        # WLS 封閉解
        XtW = X.T @ W
        beta_new = np.linalg.inv(XtW @ X) @ (XtW @ z)
        
        diff = np.max(np.abs(beta_new - beta))
        beta = beta_new
        if diff < tol:
            print(f"IRLS 演算法在第 {iteration + 1} 步成功收斂。")
            break
            
    return beta

beta_manual = fit_irls_logistic(X_design, y)

# 3. 使用 statsmodels 驗證

## 本章導讀

在許多實際應用中，我們感興趣的反應變數並非連續的數值，而是離散的**類別（Category / Class）**。例如：病患是否罹患心臟病（是/否）、金融交易是否為詐欺（真/偽）、客戶次月是否流失。這類問題統稱為**分類問題（Classification）**。

初學者常見的直覺是：「能否直接對二元類別（$0$ 與 $1$）套用線性迴歸？」答案是**不可行且理論上有重大缺陷**。為了將線性模型的優點推廣至非連續目標，統計學家提出了**廣義線性模型（Generalized Linear Models, GLM）**，而其中的皇冠正是**羅吉斯迴歸（Logistic Regression）**。

本章將剖析線性迴歸應用於分類的內在矛盾；定義勝算（Odds）與 Logit 轉換；嚴格推導基於極大似然估計（MLE）的交叉熵損失函數；給出支撐數值求解的**牛頓-拉夫森法（Newton-Raphson）**與**迭代加權最小平方法（IRLS）**之完整推導；提供一組 4 筆樣本的手把手數值推演；介紹多類別的 **Softmax 迴歸**與偏差（Deviance）模型診斷指標；最後在 R 與 Python 中進行二元分類與模型診斷實戰。

## 6.1 為什麼線性迴歸不適用於分類？

### 6.1.1 預測機率溢出問題
若對二元標籤 $Y \in \{0, 1\}$ 擬合 OLS 模型 $Y = \boldsymbol{X}\boldsymbol{\beta} + \epsilon$，並將預測值 $\hat{Y}$ 視為事件發生的條件機率 $P(Y=1 \mid \boldsymbol{X})$：
* 線性函數 $\boldsymbol{x}^\top \boldsymbol{\beta}$ 的取值範圍為 $(-\infty, \infty)$。
* 當輸入特徵偏向極端值時，預測值將不可避免地**小於 $0$ 或大於 $1$**，嚴重違背機率公理（$0 \le P \le 1$）。

### 6.1.2 異變異數性（Heteroscedasticity）
對於二元伯努利隨機變數 $Y$，其條件變異數為：
$$
\mathrm{Var}(Y \mid \boldsymbol{X}) = p(\boldsymbol{X})\left(1 - p(\boldsymbol{X})\right)
$$
誤差項的變異數直接取決於輸入特徵 $\boldsymbol{X}$，徹底破壞了 Gauss-Markov 定理中的同變異數假設。

### 6.1.3 類別編碼偏置（多類別時）
若目標變數有三個類別（例如急診室病患病情：1=輕症, 2=中症, 3=重症），若直接指派數值 $1, 2, 3$，OLS 會隱含「輕症與中症的差距」等於「中症與重症的差距」，甚至認為輕症與重症的平均就是中症，這種人為度量順序會扭曲資料本質。

## 6.2 羅吉斯模型設定與勝算比

### 6.2.1 Sigmoid 函數與 Logit 轉換

為了將實數軸 $(-\infty, \infty)$ 嚴格壓縮至機率區間 $(0, 1)$，羅吉斯迴歸採用 **標準羅吉斯函數（Standard Logistic Function / Sigmoid）**：

$$
p(\boldsymbol{x}) \triangleq P(Y = 1 \mid \boldsymbol{X} = \boldsymbol{x}) = \sigma(\boldsymbol{x}^\top \boldsymbol{\beta}) \triangleq \frac{1}{1 + e^{-\boldsymbol{x}^\top \boldsymbol{\beta}}} = \frac{e^{\boldsymbol{x}^\top \boldsymbol{\beta}}}{1 + e^{\boldsymbol{x}^\top \boldsymbol{\beta}}}
$$ {#eq-ch06-sigmoid}

#### 核心代數轉換：
1. **勝算（Odds）**：事件發生機率與不發生機率的比值：
   $$
   \mathrm{Odds} \triangleq \frac{p(\boldsymbol{x})}{1 - p(\boldsymbol{x})} = \frac{\frac{e^{\boldsymbol{x}^\top \boldsymbol{\beta}}}{1 + e^{\boldsymbol{x}^\top \boldsymbol{\beta}}}}{\frac{1}{1 + e^{\boldsymbol{x}^\top \boldsymbol{\beta}}}} = e^{\boldsymbol{x}^\top \boldsymbol{\beta}} \in (0, \infty)
   $$
2. **對數勝算（Log-Odds / Logit）**：對勝算取自然對數：
   $$
   \ln\left( \frac{p(\boldsymbol{x})}{1 - p(\boldsymbol{x})} \right) = \boldsymbol{x}^\top \boldsymbol{\beta} = \beta_0 + \beta_1 x_1 + \cdots + \beta_p x_p
   $$ {#eq-ch06-logit}

> **統計解釋（勝算比 Odds Ratio, OR）**：
> 當其他特徵固定時，特徵 $x_j$ 每增加 1 個單位，其勝算將乘以 $e^{\beta_j}$ 倍！
> * 若 $\beta_j > 0 \implies e^{\beta_j} > 1$，特徵增加會提升正類別的勝算。
> * 若 $\beta_j = 0 \implies e^{\beta_j} = 1$，該特徵對勝算毫無影響。
> * 若 $\beta_j < 0 \implies e^{\beta_j} < 1$，特徵增加會降低正類別的勝算。

## 6.3 極大似然估計（MLE）與交叉熵損失

因為非線性 Sigmoid 函數的存在，最小平方法無法求得解析解。統計上我們採用**極大似然估計（Maximum Likelihood Estimation, MLE）**。

### 6.3.1 似然函數推導

設樣本獨立同分佈，給定標籤 $y_i \in \{0, 1\}$，條件機率可統整寫為伯努利形式：
$$
P(Y = y_i \mid \boldsymbol{x}_i) = p(\boldsymbol{x}_i)^{y_i} \left(1 - p(\boldsymbol{x}_i)\right)^{1 - y_i}
$$

全體 $n$ 筆獨立樣本的**聯合似然函數（Likelihood Function）**為：
$$
L(\boldsymbol{\beta}) = \prod_{i=1}^n p(\boldsymbol{x}_i)^{y_i} \left(1 - p(\boldsymbol{x}_i)\right)^{1 - y_i}
$$

取自然對數得**對數似然函數（Log-Likelihood）**：
$$
\ell(\boldsymbol{\beta}) = \sum_{i=1}^n \left[ y_i \ln p(\boldsymbol{x}_i) + (1 - y_i) \ln (1 - p(\boldsymbol{x}_i)) \right]
$$ {#eq-ch06-log-likelihood}

將 $p(\boldsymbol{x}_i) = \frac{e^{\boldsymbol{x}_i^\top \boldsymbol{\beta}}}{1 + e^{\boldsymbol{x}_i^\top \boldsymbol{\beta}}}$ 代入展開：
$$
\begin{aligned}
\ell(\boldsymbol{\beta}) &= \sum_{i=1}^n \left[ y_i \ln\left( \frac{p(\boldsymbol{x}_i)}{1 - p(\boldsymbol{x}_i)} \right) + \ln(1 - p(\boldsymbol{x}_i)) \right] \\
&= \sum_{i=1}^n \left[ y_i (\boldsymbol{x}_i^\top \boldsymbol{\beta}) - \ln(1 + e^{\boldsymbol{x}_i^\top \boldsymbol{\beta}}) \right]
\end{aligned}
$$ {#eq-ch06-ll-simplified}

在機器學習中，我們通常將其乘以 $-1/n$，轉換為最小化**二元交叉熵損失（Binary Cross-Entropy Loss）**：
$$
\mathcal{L}(\boldsymbol{\beta}) = -\frac{1}{n}\ell(\boldsymbol{\beta}) = -\frac{1}{n}\sum_{i=1}^n \left[ y_i \ln p_i + (1 - y_i)\ln(1 - p_i) \right]
$$

## 6.4 數值最佳化：牛頓-拉夫森法與 IRLS

### 6.4.1 一階梯度向量與二階 Hessian 矩陣推導

首先計算 Sigmoid 函數的導數性質：
$$
\frac{d\sigma(z)}{dz} = \sigma(z)(1 - \sigma(z))
$$
故 $\frac{\partial p_i}{\partial \boldsymbol{\beta}} = p_i (1 - p_i) \boldsymbol{x}_i$。

#### 1. 一階梯度（Gradient Vector）：
對式 ([-@eq-ch06-ll-simplified]) 的 $\boldsymbol{\beta}$ 求一階偏導：
$$
\nabla_{\boldsymbol{\beta}} \ell(\boldsymbol{\beta}) = \sum_{i=1}^n \left( y_i \boldsymbol{x}_i - \frac{e^{\boldsymbol{x}_i^\top \boldsymbol{\beta}}}{1 + e^{\boldsymbol{x}_i^\top \boldsymbol{\beta}}} \boldsymbol{x}_i \right) = \sum_{i=1}^n (y_i - p_i)\boldsymbol{x}_i = \boldsymbol{X}^\top (\boldsymbol{y} - \boldsymbol{p})
$$ {#eq-ch06-gradient}

其中 $\boldsymbol{p} = (p_1, p_2, \dots, p_n)^\top \in \mathbb{R}^n$。

#### 2. 二階 Hessian 矩陣：
對梯度再次求導：
$$
\nabla^2_{\boldsymbol{\beta}} \ell(\boldsymbol{\beta}) = \frac{\partial}{\partial \boldsymbol{\beta}^\top} \left( \sum_{i=1}^n (y_i - p_i)\boldsymbol{x}_i \right) = -\sum_{i=1}^n \boldsymbol{x}_i \left( \frac{\partial p_i}{\partial \boldsymbol{\beta}^\top} \right) = -\sum_{i=1}^n p_i (1 - p_i) \boldsymbol{x}_i \boldsymbol{x}_i^\top
$$

定義對角權重矩陣 $\boldsymbol{W} \in \mathbb{R}^{n \times n}$：
$$
\boldsymbol{W} = \mathrm{diag}\left( p_1(1 - p_1), \, p_2(1 - p_2), \, \dots, \, p_n(1 - p_n) \right)
$$
則 Hessian 矩陣以簡潔的矩陣形式表示為：
$$
\boldsymbol{H} = \nabla^2 \ell(\boldsymbol{\beta}) = -\boldsymbol{X}^\top \boldsymbol{W} \boldsymbol{X}
$$ {#eq-ch06-hessian}

#### 凸性分析（全域最優解保證）：
由於 $0 < p_i < 1$，權重矩陣 $\boldsymbol{W}$ 的對角元素恆為正數（$p_i(1-p_i) > 0$），故 $\boldsymbol{W}$ 為正定對角矩陣。
對於任意非零向量 $\boldsymbol{v} \in \mathbb{R}^{p+1}$：
$$
\boldsymbol{v}^\top \boldsymbol{H} \boldsymbol{v} = -\boldsymbol{v}^\top (\boldsymbol{X}^\top \boldsymbol{W} \boldsymbol{X})\boldsymbol{v} = -(\boldsymbol{X}\boldsymbol{v})^\top \boldsymbol{W} (\boldsymbol{X}\boldsymbol{v}) \le 0
$$
Hessian 矩陣**恆為半負定（Negative Semi-Definite）**，證明對數似然函數 $\ell(\boldsymbol{\beta})$ 是**嚴格凹函數（Concave Function）**，沒有任何局部極大值的陷阱，保證數值最佳化必收斂至全域唯一極值點！

### 6.4.2 迭代加權最小平方法（IRLS）推導

利用多變數牛頓-拉夫森法（Newton-Raphson Update）：
$$
\boldsymbol{\beta}^{(t+1)} = \boldsymbol{\beta}^{(t)} - \left[ \nabla^2 \ell(\boldsymbol{\beta}^{(t)}) \right]^{-1} \nabla \ell(\boldsymbol{\beta}^{(t)})
$$

代入式 ([-@eq-ch06-gradient]) 與式 ([-@eq-ch06-hessian])：
$$
\begin{aligned}
\boldsymbol{\beta}^{(t+1)} &= \boldsymbol{\beta}^{(t)} - \left[ -\boldsymbol{X}^\top \boldsymbol{W}_t \boldsymbol{X} \right]^{-1} \left[ \boldsymbol{X}^\top (\boldsymbol{y} - \boldsymbol{p}_t) \right] \\
&= \boldsymbol{\beta}^{(t)} + (\boldsymbol{X}^\top \boldsymbol{W}_t \boldsymbol{X})^{-1} \boldsymbol{X}^\top (\boldsymbol{y} - \boldsymbol{p}_t) \\
&= (\boldsymbol{X}^\top \boldsymbol{W}_t \boldsymbol{X})^{-1} \left[ (\boldsymbol{X}^\top \boldsymbol{W}_t \boldsymbol{X})\boldsymbol{\beta}^{(t)} + \boldsymbol{X}^\top (\boldsymbol{y} - \boldsymbol{p}_t) \right] \\
&= (\boldsymbol{X}^\top \boldsymbol{W}_t \boldsymbol{X})^{-1} \boldsymbol{X}^\top \boldsymbol{W}_t \left[ \boldsymbol{X}\boldsymbol{\beta}^{(t)} + \boldsymbol{W}_t^{-1}(\boldsymbol{y} - \boldsymbol{p}_t) \right]
\end{aligned}
$$

定義**調整後工作反應變數（Adjusted Working Response）** $\boldsymbol{z}_t \in \mathbb{R}^n$：
$$
\boldsymbol{z}_t \triangleq \boldsymbol{X}\boldsymbol{\beta}^{(t)} + \boldsymbol{W}_t^{-1}(\boldsymbol{y} - \boldsymbol{p}_t)
$$ {#eq-ch06-working-response}

此時牛頓法更新式完美化為：
$$
\boldsymbol{\beta}^{(t+1)} = (\boldsymbol{X}^\top \boldsymbol{W}_t \boldsymbol{X})^{-1} \boldsymbol{X}^\top \boldsymbol{W}_t \boldsymbol{z}_t
$$ {#eq-ch06-irls-update}

#### 深刻結論：
式 ([-@eq-ch06-irls-update]) 正好是以 $\boldsymbol{W}_t$ 為權重矩陣、對響應變數 $\boldsymbol{z}_t$ 進行的**加權最小平方法（Weighted Least Squares, WLS）**！
這項精妙的代數等價性，使統計學家將求解 GLM 的演算法命名為**迭代加權最小平方法（Iteratively Reweighted Least Squares, IRLS）**。

## 6.5 手把手數值推演：4 筆資料之 IRLS 首步手算

為了使讀者直觀感受 IRLS 的內部運作機制，我們構造一組 4 筆樣本的 1D 分類資料：

| 樣本編號 $i$ | $x_i$ | 真實標籤 $y_i$ |
| :---: | :---: | :---: |
| 1 | 0 | 0 |
| 2 | 1 | 0 |
| 3 | 2 | 1 |
| 4 | 3 | 1 |

設計矩陣（含截距項）與標籤向量為：
$$
\boldsymbol{X} = \begin{bmatrix} 1 & 0 \\ 1 & 1 \\ 1 & 2 \\ 1 & 3 \end{bmatrix}, \quad \boldsymbol{y} = \begin{bmatrix} 0 \\ 0 \\ 1 \\ 1 \end{bmatrix}
$$

### 步驟 1：初始設定
設初始參數向量為零向量：
$$
\boldsymbol{\beta}^{(0)} = \begin{bmatrix} \beta_0^{(0)} \\ \beta_1^{(0)} \end{bmatrix} = \begin{bmatrix} 0 \\ 0 \end{bmatrix}
$$

### 步驟 2：計算各點預測機率與權重
對各樣本計算線性得分 $\eta_i = \boldsymbol{x}_i^\top \boldsymbol{\beta}^{(0)} = 0$：
$$
p_i = \sigma(0) = \frac{1}{1 + e^0} = 0.5, \quad \forall i \in \{1, 2, 3, 4\}
$$
預測機率向量為 $\boldsymbol{p}_0 = [0.5, 0.5, 0.5, 0.5]^\top$。
殘差項 $\boldsymbol{y} - \boldsymbol{p}_0$：
$$
\boldsymbol{y} - \boldsymbol{p}_0 = \begin{bmatrix} 0 - 0.5 \\ 0 - 0.5 \\ 1 - 0.5 \\ 1 - 0.5 \end{bmatrix} = \begin{bmatrix} -0.5 \\ -0.5 \\ +0.5 \\ +0.5 \end{bmatrix}
$$
對角權重矩陣元素：$w_i = p_i(1 - p_i) = 0.5 \times 0.5 = 0.25$：
$$
\boldsymbol{W}_0 = \mathrm{diag}(0.25, 0.25, 0.25, 0.25) = 0.25 \, \boldsymbol{I}_4
$$

### 步驟 3：計算一階梯度與 Hessian 矩陣
* **梯度向量**：
  $$
  \nabla \ell(\boldsymbol{\beta}^{(0)}) = \boldsymbol{X}^\top (\boldsymbol{y} - \boldsymbol{p}_0) = \begin{bmatrix} 1 & 1 & 1 & 1 \\ 0 & 1 & 2 & 3 \end{bmatrix} \begin{bmatrix} -0.5 \\ -0.5 \\ 0.5 \\ 0.5 \end{bmatrix} = \begin{bmatrix} -0.5 - 0.5 + 0.5 + 0.5 \\ 0(-0.5) + 1(-0.5) + 2(0.5) + 3(0.5) \end{bmatrix} = \begin{bmatrix} 0 \\ 2.0 \end{bmatrix}
  $$
* **加權散佈矩陣 $\boldsymbol{X}^\top \boldsymbol{W}_0 \boldsymbol{X}$**：
  $$
  \boldsymbol{X}^\top \boldsymbol{W}_0 \boldsymbol{X} = 0.25 \begin{bmatrix} 1 & 1 & 1 & 1 \\ 0 & 1 & 2 & 3 \end{bmatrix} \begin{bmatrix} 1 & 0 \\ 1 & 1 \\ 1 & 2 \\ 1 & 3 \end{bmatrix} = 0.25 \begin{bmatrix} 4 & 6 \\ 6 & 14 \end{bmatrix} = \begin{bmatrix} 1.0 & 1.5 \\ 1.5 & 3.5 \end{bmatrix}
  $$
* **求逆矩陣 $(\boldsymbol{X}^\top \boldsymbol{W}_0 \boldsymbol{X})^{-1}$**：
  行列式 $\det = (1.0)(3.5) - (1.5)^2 = 3.5 - 2.25 = 1.25 = \frac{5}{4}$。
  $$
  (\boldsymbol{X}^\top \boldsymbol{W}_0 \boldsymbol{X})^{-1} = \frac{1}{1.25} \begin{bmatrix} 3.5 & -1.5 \\ -1.5 & 1.0 \end{bmatrix} = \begin{bmatrix} 2.8 & -1.2 \\ -1.2 & 0.8 \end{bmatrix}
  $$

### 步驟 4：執行參數更新
由牛頓法：
$$
\boldsymbol{\beta}^{(1)} = \boldsymbol{\beta}^{(0)} + (\boldsymbol{X}^\top \boldsymbol{W}_0 \boldsymbol{X})^{-1} \nabla \ell(\boldsymbol{\beta}^{(0)}) = \begin{bmatrix} 0 \\ 0 \end{bmatrix} + \begin{bmatrix} 2.8 & -1.2 \\ -1.2 & 0.8 \end{bmatrix} \begin{bmatrix} 0 \\ 2.0 \end{bmatrix} = \begin{bmatrix} -2.4 \\ 1.6 \end{bmatrix}
$$

### 步驟 5：加權最小平方 WLS 視角驗證
計算工作反應變數 $\boldsymbol{z}_0 = \boldsymbol{X}\boldsymbol{\beta}^{(0)} + \boldsymbol{W}_0^{-1}(\boldsymbol{y} - \boldsymbol{p}_0) = \boldsymbol{0} + \frac{1}{0.25}(\boldsymbol{y} - \boldsymbol{p}_0) = 4(\boldsymbol{y} - \boldsymbol{p}_0)$：
$$
\boldsymbol{z}_0 = \begin{bmatrix} 4(-0.5) \\ 4(-0.5) \\ 4(0.5) \\ 4(0.5) \end{bmatrix} = \begin{bmatrix} -2 \\ -2 \\ 2 \\ 2 \end{bmatrix}
$$
計算 $\boldsymbol{X}^\top \boldsymbol{W}_0 \boldsymbol{z}_0$：
$$
\boldsymbol{X}^\top \boldsymbol{W}_0 \boldsymbol{z}_0 = 0.25 \begin{bmatrix} 1 & 1 & 1 & 1 \\ 0 & 1 & 2 & 3 \end{bmatrix} \begin{bmatrix} -2 \\ -2 \\ 2 \\ 2 \end{bmatrix} = 0.25 \begin{bmatrix} 0 \\ 8 \end{bmatrix} = \begin{bmatrix} 0 \\ 2 \end{bmatrix}
$$
套用 WLS 解：
$$
\boldsymbol{\beta}^{(1)} = (\boldsymbol{X}^\top \boldsymbol{W}_0 \boldsymbol{X})^{-1} (\boldsymbol{X}^\top \boldsymbol{W}_0 \boldsymbol{z}_0) = \begin{bmatrix} 2.8 & -1.2 \\ -1.2 & 0.8 \end{bmatrix} \begin{bmatrix} 0 \\ 2 \end{bmatrix} = \begin{bmatrix} -2.4 \\ 1.6 \end{bmatrix}
$$
牛頓步與 WLS 閉式解**完美一致**！

> 💡 **幾何意義解讀**：
> 在僅僅第 1 步迭代後，模型的分界決策面為 $-2.4 + 1.6x = 0 \implies x^* = \frac{2.4}{1.6} = 1.5$！
> 決策分界線精準落在類別 0（$x \in \{0, 1\}$）與類別 1（$x \in \{2, 3\}$）的中間點 $x=1.5$ 處，展現了二階最佳化極高的收斂效率。

## 6.6 模型評估與診斷指標：偏差（Deviance）與 AIC

在廣義線性模型中，衡量配適度優劣不再使用最小平方法的殘差平方和（$\mathrm{RSS}$），而是使用**偏差（Deviance）**。

### 6.6.1 飽和模型與偏差定義
* **飽和模型（Saturated Model）**：假設模型參數個數等於樣本數（$p = n$），能完美配適每一筆資料，其對數似然為 $\ell_{\text{sat}}$。
* **擬合模型（Fitted Model）**：使用 $p+1$ 個參數估計，其最大對數似然為 $\ell(\hat{\boldsymbol{\beta}})$。
* **殘差偏差（Residual Deviance, $D$）**：
  $$
  D \triangleq 2 \left[ \ell_{\text{sat}} - \ell(\hat{\boldsymbol{\beta}}) \right]
  $$
  在二元羅吉斯迴歸中，飽和模型的 $\hat{p}_i = y_i$，故 $\ell_{\text{sat}} = 0$。因此：
  $$
  D = -2 \ell(\hat{\boldsymbol{\beta}}) = -2 \sum_{i=1}^n \left[ y_i \ln \hat{p}_i + (1 - y_i) \ln(1 - \hat{p}_i) \right]
  $$
* **虛無偏差（Null Deviance, $D_0$）**：僅包含截距項（所有樣本預測機率皆為 $\bar{y}$）的偏差值。
* **模型顯著性之似然比檢定（Likelihood Ratio Test, LRT）**：
  $$
  \Delta D = D_0 - D = 2\left[ \ell(\hat{\boldsymbol{\beta}}) - \ell(\hat{\beta}_0) \right] \sim \chi^2_p
  $$
  若 $p$-value 極小，拒絕虛無假設，證明引入的 $p$ 個特徵整體對模型有顯著解釋力。

### 6.6.2 赤池資訊準則（AIC）
$$
\mathrm{AIC} = -2\ell(\hat{\boldsymbol{\beta}}) + 2(p + 1) = D + 2(p + 1)
$$
在配適優度與參數懲罰項之間取得平衡，數值越小代表模型越優。

## 6.7 多類別推廣：Softmax 迴歸

當類別數量 $K > 2$ 時，模型推廣為多項羅吉斯迴歸（Multinomial Logistic Regression / Softmax）：

$$
P(Y = k \mid \boldsymbol{x}) = \frac{e^{\boldsymbol{x}^\top \boldsymbol{\beta}_k}}{\sum_{l=1}^K e^{\boldsymbol{x}^\top \boldsymbol{\beta}_l}}, \quad k = 1, 2, \dots, K
$$ {#eq-ch06-softmax}

為了保證參數可辨識性，通常固定最後一類作為基準類別（令 $\boldsymbol{\beta}_K = \boldsymbol{0}$）。Softmax 函數是現代深度神經網路輸出層分類任務的標準配置。

### 🟨 Python 雙軌實作

```python
# ==============================================================================
# Python 實作：手刻 IRLS 演算法與 statsmodels Logit 詳細報表驗證
# 依賴套件：numpy, pandas, statsmodels, sklearn
# ==============================================================================

import numpy as np
import pandas as pd
import statsmodels.api as sm
from sklearn.metrics import classification_report, roc_auc_score

# 1. 模擬二元分類資料集
np.random.seed(42)
n = 500
x1 = np.random.normal(0, 1, n)
x2 = np.random.normal(0, 1, n)
X_design = np.column_stack([np.ones(n), x1, x2])
beta_true = np.array([-0.5, 1.8, -1.2])

prob_true = 1.0 / (1.0 + np.exp(-X_design @ beta_true))
y = np.random.binomial(1, prob_true, size=n)

# 2. 手刻迭代加權最小平方法 (IRLS)
def fit_irls_logistic(X, y, max_iter=20, tol=1e-6):
    n_samples, p_features = X.shape
    beta = np.zeros(p_features) # 初始化為零
    
    for iteration in range(max_iter):
        p = 1.0 / (1.0 + np.exp(-X @ beta))
        p = np.clip(p, 1e-15, 1 - 1e-15) # 防止數值溢出
        
        w = p * (1.0 - p)
        W = np.diag(w)
        
        # 工作反應變數 z
        z = X @ beta + (y - p) / w
        
        # WLS 封閉解
        XtW = X.T @ W
        beta_new = np.linalg.inv(XtW @ X) @ (XtW @ z)
        
        diff = np.max(np.abs(beta_new - beta))
        beta = beta_new
        if diff < tol:
            print(f"IRLS 演算法在第 {iteration + 1} 步成功收斂。")
            break
            
    return beta

beta_manual = fit_irls_logistic(X_design, y)

# 3. 使用 statsmodels 驗證
logit_model = sm.Logit(y, X_design).fit(disp=False)

print("\n=== 係數估計對比 ===")
print("真實參數向量:", beta_true)
print("手刻 IRLS 估計值:", np.round(beta_manual, 4))
print("statsmodels 估計值:", np.round(logit_model.params, 4))

# 4. 輸出 statsmodels 摘要指標
print(logit_model.summary())
print(f"ROC AUC 分數: {roc_auc_score(y, logit_model.predict(X_design)):.4f}")
```

## 6.9 課後全方位習題庫（10 題）

### 一、觀念理解與數學證明（5 題）

1. **Sigmoid 函數的一階導引理證明**：
   嚴格推導 $\sigma'(z) = \sigma(z)(1 - \sigma(z))$，並解釋為什麼在反向傳播或梯度下降中，當預測極度確信（$z \to \pm \infty$）時會導致梯度消失（Vanishing Gradient）。
2. **似然函數嚴格凹性之二次型證明**：
   證明式 ([-@eq-ch06-hessian]) 的 Hessian 矩陣 $\boldsymbol{H} = -\boldsymbol{X}^\top \boldsymbol{W} \boldsymbol{X}$ 在特徵矩陣 $\boldsymbol{X}$ 具備行滿秩（Full Column Rank）條件下，恆為嚴格負定（Negative Definite），並論證為什麼羅吉斯迴歸不存在局部極小值。
3. **勝算比（Odds Ratio）的乘法可加性**：
   設羅吉斯迴歸中某特徵 $x_1$ 增加 $\Delta$ 個單位，證明勝算比變化倍率為 $e^{\beta_1 \Delta}$。若 $x_1$ 為連續變數（如年齡），請從流行病學風險角度解釋此性質的臨床價值。
4. **完全分離（Complete Separation）與 Hauck-Donner 效應**：
   當訓練資料存在某個特徵子集使得兩類標籤可以被完全分開（例如 $x > c$ 時標籤全為 1，$x \le c$ 時標籤全為 0），證明此時 MLE 的參數估計值 $\hat{\beta} \to \infty$。請解釋為什麼此時標準統計軟體報告的 Wald $z$-統計量會反常偏小（Hauck-Donner 效應）？
5. **多項 Softmax 迴歸對二元羅吉斯之退化性證明**：
   在式 ([-@eq-ch06-softmax]) 中令類別數 $K=2$，並固定基準類別 $\boldsymbol{\beta}_2 = \boldsymbol{0}$，證明此時的類別機率公式退化為式 ([-@eq-ch06-sigmoid]) 的標準二元羅吉斯迴歸。

### 二、程式實作與實務應用（5 題）

6. **正則化羅吉斯迴歸（$L_1$ / $L_2$ Regularized Logistic）實作**：
   在羅吉斯迴歸損失函數中加入 $L_1$ 懲罰項（Lasso Logistic Regression），使用 Python `LogisticRegression(penalty='l1', solver='liblinear')` 或 R `glmnet(..., family="binomial", alpha=1)` 擬合高維度模擬數據，繪製係數收縮路徑圖並找出關鍵預測特徵。
7. **最佳分類閥值之成本敏感搜尋（Cost-Sensitive Threshold Tuning）**：
   在癌症診斷中，偽陰性（漏診）的代價是偽陽性（誤診）的 10 倍。撰寫程式繪製不同分類閥值 $\tau \in [0.01, 0.99]$ 下的總損失成本曲線，並找出最優預測閥值 $\tau^*$。
8. **完全分離問題之 Firth 懲罰似然法（Firth's Penalized Likelihood）**：
   構造一組完全線性可分的二元資料集。展示普通 `glm()` 產生警告並輸出極端係數；接著使用 R 的 `logistf` 套件或 Python 實作 Jeffreys 先驗懲罰似然估計（Firth Logistic Regression），驗證其如何克服參數發散。
9. **校準曲線（Calibration Curve / Reliability Diagram）與 Brier Score**：
   產生一組二元測試資料，計算模型的 Brier Score：$\mathrm{BS} = \frac{1}{n}\sum_{i=1}^n (\hat{p}_i - y_i)^2$。繪製可靠度圖，評估模型預測機率是否具有良好的經驗校準性（Well-Calibrated）。
10. **多類別 Softmax 混淆矩陣與宏觀/微觀指標計算（Macro vs Micro F1）**：
    利用真實多分類資料集（如 Iris 或 MNIST 子集），擬合多項羅吉斯迴歸模型。手動計算多類別混淆矩陣，並分別編程實現 Micro-$F_1$、Macro-$F_1$ 與 Weighted-$F_1$ 之計算。
