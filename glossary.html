Statistical Inference 統計推論 统计推断 由樣本數據推估母體參數、檢驗統計假設之過程。
Overfitting / Underfitting 過度配適 / 配適不足 过拟合 / 欠拟合 模型過度捕捉訓練資料雜訊，或模型容量過小無法捕捉規律。
Bias-Variance Tradeoff 偏誤-變異數權衡 偏差-方差权衡 泛化誤差分解為模型自身偏誤與估計變異數之間的結構性取捨。
Residual / Error 殘差 / 誤差 残差 / 误差 殘差為樣本觀測值與估計值之差；誤差為觀測值與真實母體值之差。
Regression 迴歸 回归 研究連續型應變數與一個或多個自變數之間統計關聯的分析方法。
Logistic Regression 羅吉斯迴歸 逻辑斯谛回归 / 对数几率回归 採用 Logit 連結函數處理二元或多元離散類別之廣義線性模型。
Cross-Validation 交叉驗證 交叉验证 將資料集劃分為訓練組與驗證組，重複評估模型泛化能力之重抽樣技術。
Bootstrap 自助法 / 靴拔法 自助法 / 拔靴法 從原始樣本中進行有放回抽樣（Sampling with Replacement）的非參數方法。
Regularization / Shrinkage 正則化 / 縮減法 正则化 / 收缩法 在損失函數中加入懲罰項以限制模型複雜度、防止過度配適之技術。
Support Vector Machine (SVM) 支援向量機 支持向量机 藉由最大化分類邊界間距（Margin）以求解超平面之二次規劃分類器。
Perceptron 感知器 感知机 由 Rosenblatt 提出之早期線性二元分類神經元模型。
Naive Bayes 單純貝氏 / 樸素貝氏 朴素贝叶斯 基於特徵條件獨立假設之貝氏後驗機率生成式分類器。
Robust / Robustness 穩健 / 強健性 鲁棒 / 鲁棒性 統計估計量對於極端離群值或非常態母體之抗干擾能力。
Lagrange Multipliers 拉格朗日乘數 拉格朗日乘子 於約束最佳化問題中將約束條件轉換至目標函數的權重係數。
Generalization Error 一般化誤差 / 泛化誤差 泛化误差 模型在未知新樣本（母體分佈）上的期望預測誤差。
Empirical Risk 經驗風險 经验风险 模型在既有訓練樣本集上的平均經驗損失。
Covariate Shift 共變量偏移 协变量偏移 輸入特徵的分佈 P(X) 發生改變，但條件機率分佈 P(Y \mid X) 保持不變之現象。
False Discovery Rate (FDR) 偽發現率 错误发现率 多重假設檢定中，拒絕虛無假設之案件中型一誤差（偽陽性）之期望比例。

數學符號約定系統表

本書統一採用現代統計學與線性代數通用之數學符號規範，全書各章定義完全一致：

  • 標量（Scalars）：使用斜體小寫字母，如 y \in \mathbb{R}、p \in \mathbb{N}。
  • 向量（Vectors）：使用粗體斜體小寫字母，如 \boldsymbol{x} = (x_1, x_2, \dots, x_p)^\top \in \mathbb{R}^p。所有向量預設為行向量（Column Vector）。
  • 矩陣（Matrices）：使用粗體大寫字母，如設計矩陣 \boldsymbol{X} \in \mathbb{R}^{n \times p}。
  • 隨機變數（Random Variables）：使用大寫斜體字母，如 X, Y, \epsilon。
  • 估計量（Estimators）：在參數上方標註帽子符號（Hat），如 \hat{\boldsymbol{\beta}} 代表參數 \boldsymbol{\beta} 之樣本估計值；\hat{y} 代表預測值。
  • 期望值與變異數：期望值記為 \mathbb{E}[X]；變異數記為 \mathrm{Var}(X)；共變異數矩陣記為 \mathrm{Cov}(\boldsymbol{X})。
  • 範數（Norms）：
    • L_1 範數：\|\boldsymbol{\beta}\|_1 = \sum_{j=1}^p |\beta_j|
    • L_2 範數：\|\boldsymbol{\beta}\|_2 = \sqrt{\sum_{j=1}^p \beta_j^2} = \sqrt{\boldsymbol{\beta}^\top \boldsymbol{\beta}}
    • 矩陣 Frobenius 範數：\|\boldsymbol{A}\|_F = \sqrt{\mathrm{tr}(\boldsymbol{A}^\top \boldsymbol{A})}

## 數學符號約定系統表

本書統一採用現代統計學與線性代數通用之數學符號規範，全書各章定義完全一致：

* **標量（Scalars）**：使用斜體小寫字母，如 $y \in \mathbb{R}$、$p \in \mathbb{N}$。
* **向量（Vectors）**：使用**粗體斜體小寫字母**，如 $\boldsymbol{x} = (x_1, x_2, \dots, x_p)^\top \in \mathbb{R}^p$。所有向量預設為**行向量（Column Vector）**。
* **矩陣（Matrices）**：使用**粗體大寫字母**，如設計矩陣 $\boldsymbol{X} \in \mathbb{R}^{n \times p}$。
* **隨機變數（Random Variables）**：使用大寫斜體字母，如 $X, Y, \epsilon$。
* **估計量（Estimators）**：在參數上方標註帽子符號（Hat），如 $\hat{\boldsymbol{\beta}}$ 代表參數 $\boldsymbol{\beta}$ 之樣本估計值；$\hat{y}$ 代表預測值。
